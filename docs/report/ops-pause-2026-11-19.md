## Công việc khi tiếp tục

1. Sửa resolution BullMQ/AJV và kiểm tra toàn bộ peer dependency bằng npm được ghim; không miễn trừ advisory để vượt gate.
2. Chạy clean install, audit thực thi, lint/typecheck/build, unit, HTTP cô lập, browser và smoke container trên revision cuối.
3. Cập nhật bằng chứng và PR sau khi CI hoàn tất; chủ repository vẫn cần bật branch protection.
4. Chỉ triển khai khi các cổng kiểm tra đạt. SNS confirmation/test alert được hoãn theo yêu cầu.

AWS preview được yêu cầu hibernate, giữ nguyên data/foundation; kiểm tra trạng thái thực tế bằng runbook trước khi khởi động lại.
